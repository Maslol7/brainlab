# Nav

A floating bottom bar with the four main places: journey, games, progress, shop.

- Four items, icon over a word. The current icon sits in an `acc` pill (`ni`), its word turns `ink`, and the button has aria-current.
- The bar floats 12px from the edges with a 28px radius and a blur; the sky fades in under it.
- Fixed to the bottom with the safe-area inset; screens keep `nav-clearance` free under their content.
