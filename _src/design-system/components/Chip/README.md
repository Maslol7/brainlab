# Chip

Small rounded labels: `chip` is tappable, `tag` names a category, `combo` counts a streak.

- `chip`: secondary choices (amounts, reasons, filters). `chip.hot` (gold) marks the one that matters now.
- `tag`: the category of a question, in the world accent. `tag.rev` (gold) marks a question from the mistakes notebook.
- `combo`: flame + number, gold, only from 2 correct answers in a row.
